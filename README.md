## 1) Definição

O Hypertext Markup Language, ou popularmente conhecido como HTML, é uma linguagem de marcação usada no desenvolvimento de aplicações front-end. Ao contrário do que muitos pensam, o HTML não é considerada uma linguagem de programação propriamente dita. Esta linguagem de marcação permite a estruturação e a exibição de conteúdos em páginas web.

O HTML apresenta as seguintes funções primárias:

1) Permitir a inserção de textos, imagens, botões e outros recursos dentro de uma página web.
2) Definir a estrutura e a semântica de um conteúdo dentro de uma página web.
3) Indicar aos diferentes tipos de navegadores como as páginas web devem ser visualizadas.
4) Contribuir através do uso de tags semânticas e estratégias de SEO para o melhor ranqueamento do site nos buscadores.
5) Contribuir para a acessibilidade da página web pelo uso de atributos aria e alt.

Tendo em vista, estas informações iniciais, vamos prosseguir para entender a estrutura básica de um documento html.
